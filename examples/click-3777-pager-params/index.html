pallets/click#3777

Forward PAGER parameters to the temp-file pager and parse less flags

3 files changed +227 −12

Summary

_tempfilepager now passes the parameters from PAGER to the pager, before the temporary file name. On Windows, PAGER="less -R" now runs less -R instead of bare less.

The PR also replaces the substring check for raw mode in _pipepager. The new _less_uses_raw_mode splits LESS and the pager arguments into tokens. Only short-option clusters with an r, and --raw-control-chars, count as a raw-mode request. This removes false positives from filenames such as requirements.txt. It also changes the result for a LESS value without a dash, such as FRX.
